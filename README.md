# Aditi: Elevated Portfolio

Build a complete, production-ready personal portfolio website for ADITI S PRASAD.

IMPORTANT:
This is a PERSONAL PORTFOLIO, not a SaaS dashboard and not a resume webpage.

The portfolio should feel like a premium creative-tech personal website: minimal, elegant, aesthetic, immersive, sophisticated and visually memorable.

The design should be inspired by high-end editorial, fashion-tech and creative developer portfolios, while remaining completely original.
